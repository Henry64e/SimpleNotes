# SimpleNotes

Простое приложение на FastAPI для хранения одной текстовой заметки.
Позволяет прочитать, сохранить и очистить заметку.
Текст сохраняется в файле и остается после перезапуска приложения.

## Установка

Требуется Python 3.10 или новее.
Все команды выполняются из папки проекта.

### Windows (PowerShell)

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
```

### Linux

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
```

## Запуск

### Windows

```powershell
.\.venv\Scripts\python.exe -m uvicorn app_final:app
```

### Linux

```bash
.venv/bin/python -m uvicorn app_final:app
```

Документация API: http://127.0.0.1:8000/docs

Для разработки можно добавить к команде запуска `--reload`.
Для остановки сервера нажмите Ctrl+C.

## Маршруты

| Метод | Путь | Назначение |
|---|---|---|
| GET | /health | Проверка работоспособности |
| GET | /version | Версия приложения |
| GET | /note | Чтение заметки |
| POST | /save | Сохранение заметки |
| POST | /clear | Очистка заметки |

Для сохранения откройте `/docs`, выберите POST `/save`,
нажмите Try it out и передайте:

```json
{"text": "Моя заметка"}
```

Затем нажмите Execute. Новое сохранение заменяет предыдущий текст.
Если в запросе нет поля `text`, приложение возвращает ошибку 422.

## Настройки

Переменная окружения `NOTE_FILENAME` задает имя файла заметки.
По умолчанию используется `note.txt` рядом с `app_final.py`.
Указывайте только имя файла, без пути к папке.

Пример для PowerShell, перед запуском сервера:

```powershell
$env:NOTE_FILENAME = "note.txt"
```

Пример для Linux:

```bash
export NOTE_FILENAME=note.txt
```

Файл `.env.example` содержит образец настройки.
Приложение не загружает файлы `.env` автоматически.

## Тесты

Windows:

```powershell
.\.venv\Scripts\python.exe -m pytest -v
```

Linux:

```bash
.venv/bin/python -m pytest -v
```

Четыре теста проверяют работоспособность, сохранение и чтение,
очистку и запрос без обязательного поля.
Тесты используют временные файлы и не изменяют личную заметку.

## Проверка и диагностика

- Откройте http://127.0.0.1:8000/health.
  Ожидаемый ответ: `{"status":"ok"}`.
- Откройте http://127.0.0.1:8000/version.
  Ожидаемый ответ: `{"version":"1.0.0"}`.
- Логи запуска и запросов видны в терминале с сервером.
  Приложение также сообщает о чтении, сохранении и очистке.
- Если браузер не подключается, проверьте, что сервер запущен.
- Если порт 8000 занят, остановите предыдущий сервер
  или добавьте `--port 8001` и используйте этот порт в браузере.
- При ошибке записи проверьте права на папку проекта
  и значение `NOTE_FILENAME`.

## Безопасность

Приложение предназначено для локального учебного использования.
Авторизации нет. Не хранить в заметке пароли и токены!
Файлы `.env`, `note.txt` и виртуальное окружение исключены из Git.
При выборе другого имени файла заметки добавьте его в `.gitignore`.
